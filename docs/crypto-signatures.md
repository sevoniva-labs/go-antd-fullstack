# 签名与验签边界

脚手架提供统一的 `crypto.Signer` 应用边界，便于审批、报文完整性和审计链路使用。机构批准的 KMS、HSM 或密码机适配器可以实现同一接口，私钥不应进入业务进程。

`SM2SoftwareSigner` 只用于开发和测试基线：它使用显式用户 ID、SM2-SM3 签名和验签，并在上下文取消、空消息、错误签名时失败关闭。它不代表密码机、国密 TLS、证书链、密钥托管、双人双控或密评通过。

生产启动必须注入设备适配器，并为具体目标提供 `Target-tested` 证据；没有设备适配器时，生产配置继续由 bootstrap 的 fail-closed 规则拒绝启动。
